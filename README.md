# homebrew-tap

Homebrew tap for [**vajra**](https://github.com/ifelse-codes/vajra) — one CLI that guides any AI
coding agent through your project, step by step. The formula installs the prebuilt `vajra` binary
from the project's GitHub release (sha256-verified).

```bash
brew install ifelse-codes/tap/vajra
vajra --help
```

Supports macOS (Apple Silicon + Intel) and Linux (x86_64). Apache-2.0.
